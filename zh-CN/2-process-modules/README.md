# 第 2 部　制程模块

晶圆厂里的步骤多达数百到上千个，但大部分都是由几种基本的「制程模块」反复组合而成。这一部逐一介绍每个模块：它在做什么、用什么机台、要看哪些指针、常出什么问题。

实际生产时，晶圆会在这些模块之间反复循环：铺上薄膜、微影、蚀刻或布植、清洗、量测，然后再往上做下一层。本书从微影开始介绍，因为它是整个循环的内核。

| 章节 | 你会读到 |
|---|---|
| [第 4 章　微影](04-lithography/README.md) | 光罩、光阻与曝光机，把电路图「印」到晶圆上 |
| [第 5 章　薄膜](05-thin-films/README.md) | 热氧化、CVD、PVD、ALD 与磊晶 |
| [第 6 章　蚀刻](06-etching/README.md) | 干蚀刻与湿蚀刻、电浆、选择比与终点侦测 |
| [第 7 章　离子布植与热处理](07-ion-implantation/README.md) | 剂量、能量、退火与热预算 |
| [第 8 章　CMP](08-cmp/README.md) | 把晶圆磨平：研磨液、碟化、侵蚀与假图形 |
| [第 9 章　清洗与污染控制](09-cleaning/README.md) | RCA 清洗、Q-Time 与交叉污染 |
| [第 10 章　金属化](10-metallization/README.md) | 接触窗、铜的大马士革制程与低介电常数材料 |
